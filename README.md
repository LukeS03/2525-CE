# 2525 CE
A game by Luke Shanks.

This game was created for the University of Sussex's HackSussex 2024 Hackathon, and it is inspired by games like Minecraft, Terraria and Minicraft (a 2D top-down game made by Notch for a Ludum Dare challenge). 

It utilises the Godot engine, and it is aimed at the **BCS "Most Sustainable Hack"** and **HackSussex "Hack Artistry"** tracks.

In the end, I never ended up submitting it. The project remains unfinished because I had started to lose focus towards the night, and I encountered some rather annoying errors with Git which overwrote some of the work I did. Overall, it was a very fun experience, but I don't think that the Hackathon format fits me. Maybe if I tried doing the Hackathon as part of a team I would have been able to help deliver a working product, but I was a bit stubborn with regards to my desire to use Godot as my engine of choice.
